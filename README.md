# NEGATIVE

A tiny 1-bit top-down roguelike shooter. One Python file, no assets: sprites are drawn in code and sounds are synthesized at startup.

```sh
python negative.py   # needs pygame (pacman -S python-pygame)
```

**Controls:** WASD move · mouse aim · LMB fire · RMB/Space roll · E pick up · Q/wheel swap · Esc pause · F11 fullscreen

Clear each procedural cave to open a portal, collect rads to level up and pick mutations, and face The Warden every third level.
