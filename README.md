# tiny-games

Small single-file pygame games. Each runs with nothing but `pygame` (`pacman -S python-pygame`).

| Game | Run | |
|---|---|---|
| [NEGATIVE](negative/) | `python negative/negative.py` | 1-bit top-down roguelike shooter |
| [GRAVEN](graven/) | `python graven/graven.py` | dark-fantasy top-down roguelike: melee, spells, torchlight |
